Saga Techbox Deur installeren

Kies je apparaat, download het bestand en volg de drie stappen.

De downloads staan in een privé-omgeving: je moet ingelogd zijn bij GitHub met jouw account, anders zie je een foutmelding.

Eén bestand dat zelf je apparaat herkent Mac, Windows of Linux — dubbelklik en klaar

Mac of Linux .zip Windows .zip
  1. Download het bestand voor jouw computer en pak het uit (dubbelklik op de .zip).
  2. Mac/Linux: dubbelklik op Installeer.command (Linux: bash Installeer.command). Windows: dubbelklik op Installeer-Windows.bat.
  3. Het bestand ziet welke computer je hebt (Apple-chip of Intel, Windows, Linux), haalt de nieuwste versie op en start de installatie. De eerste keer log je eenmalig in bij GitHub.

Zegt je Mac dat het bestand niet geopend kan worden? Rechtsklik erop → Open → Open.

Windows pc of laptop — installatiebestand .exe

Download voor Windows .exe
  1. Dubbelklik op het bestand dat je hebt gedownload.
  2. Staat er “Windows heeft uw pc beschermd”? Klik op Meer info en dan op Toch uitvoeren.
  3. Klik door de installatie. Vraagt de firewall iets? Kies Toestaan.

Open daarna Saga Techbox Deur in het startmenu.

Mac macOS — installatiebestand .pkg

Mac met Apple-chip .pkg · M1 en nieuwer Mac met Intel .pkg
  1. Dubbelklik op het bestand en klik door het installatievenster. De app komt vanzelf in Programma’s.
  2. Zegt de Mac dat het bestand niet geopend kan worden (onbekende ontwikkelaar)? Rechtsklik op het bestand → Open → Open. Of: Systeeminstellingen → Privacy en beveiliging → Toch openen.
  3. Zegt de Mac later dat de app “beschadigd” is? Plak dit één keer in Terminal:
xattr -cr "/Applications/Saga Techbox Deur.app"

Liever slepen? Er is ook een .dmg (Intel). Niet zeker welke chip? Klik op → Over deze Mac: staat er “Apple M…”, kies dan Apple-chip.

De eerste keer starten op elke computer

De app vraagt één ding: wat is deze computer? Kies er één van vier:

  1. Alles-in-één — de makkelijkste keuze. Eén computer is server én bedieningspaneel.
  2. Deurscherm — de monitor bij de deur. Vul het adres van de server in (of kies "op deze computer").
  3. Bedieningspaneel — jouw werkplek. Vul het adres van de server in.
  4. Alleen de server — draait onzichtbaar op de achtergrond. Een icoontje bij de klok toont het adres.

Je kunt dit later altijd veranderen met Ctrl/Cmd + Shift + S.

iPhone en iPad alleen voor jouw eigen toestel

Eén commando (als je Xcode en een kabel hebt)

Sluit je iPhone of iPad aan, ontgrendel hem en tik op Vertrouw. Haal dan het project op een vaste plek en voer uit (vervang JOUWTEAMID door je Apple-team, te vinden in Xcode → Instellingen → Accounts):

cd ~/Documents && git clone https://github.com/Milo289/saga-techbox-door.git && cd saga-techbox-door/ios
./install.sh --team JOUWTEAMID          # de gewone app (Deur Beheer)
./install.sh dev --team JOUWTEAMID      # de ontwikkelaarsversie (Deur Dev), naast de gewone

Er zijn twee apps: Deur Beheer is de gewone app. Deur Dev is dezelfde app met een extra tabblad Ontwikkelaar (live gebeurtenissen, ruwe gegevens, API-console, tests). Wil je dat in de gewone app? Tik 7 keer op Versie onder Instellingen.

Optie 1 — met Xcode (het makkelijkst als je Xcode al hebt)

  1. Haal het project op een vaste plek (niet in een tijdelijke map) en maak het Xcode-project: 
    cd ~/Documents && git clone https://github.com/Milo289/saga-techbox-door.git && cd saga-techbox-door/ios && brew install xcodegen && xcodegen generate && open DeurBeheer.xcodeproj
  2. Voeg in Xcode je Apple-ID toe: Xcode → Instellingen → Accounts → +. Kies bij het project DeurBeheer → Signing & Capabilities → Team jouw naam. Staat er een rode melding over de Bundle Identifier? Verander hem dan naar iets eigens, bijvoorbeeld nl.jouwnaam.deurbeheer.
  3. Sluit je iPhone aan, zet Ontwikkelaarsmodus aan (Instellingen → Privacy en beveiliging), kies je iPhone bovenin Xcode en druk op ▶︎.
  4. Op de iPhone: Instellingen → Algemeen → VPN en apparaatbeheer → tik op je Apple-ID → Vertrouw. Open daarna Deur Beheer.

Werkt Xcode-beta niet met jouw iPhone (“toestel niet ondersteund”)? Een bètaversie ondersteunt soms alleen toestellen met een bijpassende bèta-iOS. Gebruik dan de gewone Xcode uit de App Store, of optie 2.

Optie 2 — zonder Xcode, met Sideloadly

Download voor iPhone .ipa Sideloadly downloaden
  1. Installeer Sideloadly (gratis), sluit je iPhone aan en kies “Vertrouw deze computer”. Zet Ontwikkelaarsmodus aan.
  2. Sleep het .ipa-bestand in Sideloadly, vul je Apple-ID in en klik op Start.
  3. Op de iPhone: Instellingen → Algemeen → VPN en apparaatbeheer → Vertrouw.

Daarna: open Deur Beheer en vul het adres van je server, je gebruikersnaam en wachtwoord in.

Goed om te weten: Apple laat alleen apps toe die met een eigen account zijn ondertekend. Met een gratis Apple-ID werkt de app 7 dagen; installeer hem daarna opnieuw (met Xcode: gewoon weer ▶︎). Met het betaalde Apple Developer-programma duurt het een jaar.

Linux en Raspberry Pi bestand eindigt op .AppImage of .deb

Linux-pc AppImage Linux-pc .deb Raspberry Pi AppImage Raspberry Pi .deb
  1. AppImage: maak het uitvoerbaar met chmod +x bestandsnaam en dubbelklik of start het.
  2. .deb: installeer met sudo apt install ./bestandsnaam.

De eerste keer openen

  1. Windows, Mac, Linux: de app vraagt wat de computer doet. Kies Deurscherm (de monitor bij de deur) of Bedieningspaneel (om te bedienen), en of de server op deze computer draait of op een andere.
  2. iPhone: vul het adres van de server in, bijvoorbeeld 192.168.2.27:8080 of je tunneladres, met je gebruikersnaam en wachtwoord.
  3. Een andere keuze maken? Op de computer: Ctrl/Cmd + Shift + S opent de instellingen opnieuw.

Altijd blijven werken, zonder betaald developer-account

Een app op je iPhone of iPad die je met een gratis Apple-ID zelf installeert, stopt na 7 dagen. Dat is een regel van Apple, die ik niet kan uitzetten. Zo houd je het toch werkend:

ApparaatBlijft het werken?Hoe
MacJa, altijdDe Mac-app (.pkg) heeft geen tijdslimiet en heeft geen developer-account nodig.
Windows en LinuxJa, altijdGeen limiet.
iPhone en iPad — als web-appJa, altijd, gratisOpen het adres van je server met /admin in Safari → Deel-knop → Zet op beginscherm. Er komt een icoon op je beginscherm dat voor altijd blijft. Dit heeft geen Face ID, Siri of trillen; de rest werkt.
iPhone en iPad — echte app, ververst zichzelfJa, gratisGebruik AltStore (altstore.io) of SideStore: een klein programma op je Mac of pc ververst de app elke week vanzelf via wifi, zolang die computer aan staat en op hetzelfde wifi zit. Je installeert de .ipa (zie hieronder) één keer met AltStore.
iPhone en iPad — echte app, zelf verversenElke 7 dagenOpnieuw op ▶ drukken in Xcode, of in Sideloadly op Start klikken. Met een gratis Apple-ID kun je maximaal 3 eigen apps tegelijk hebben.
iPhone en iPad — met Apple Developer ProgramJa, 1 jaar (of 90 dagen via TestFlight)Kost 99 dollar per jaar. Dan werkt de app een jaar lang en kun je hem via TestFlight delen. Alleen nodig als je de echte app écht permanent wilt zonder gedoe.

Mijn advies: Mac, Windows en Linux gewoon installeren. Op de iPhone en iPad de web-app op het beginscherm zetten (altijd gratis) en, als je Face ID en trillen wilt, de echte app met AltStore.
