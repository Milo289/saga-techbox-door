# Handige opties (onderzoek)

Alles opt-in en gratis. ✅ = gebouwd, ⏳ = nog niet.

| Optie | Waarom | Status |
|---|---|---|
| Energieschema (scherm/computer uit en aan) | Op school geen stroom buiten schooltijd | ✅ |
| Kleurthema’s en eigen uiterlijk per apparaat | Eén knop voor het hele uiterlijk | ✅ |
| Server automatisch vinden | Geen IP-adres intypen | ✅ |
| Downloadpagina `/get` | Anderen kunnen de app zelf ophalen | ✅ |
| Windows portable (zonder installatie) | Geen beheerdersrechten nodig | ✅ |
| Melding als het deurscherm offline is | Merken dat het scherm uit/kapot is | ⏳ |
| Dagelijkse herstart | Houdt het scherm stabiel | ✅ (via energieactie) |
| Raspberry Pi als server | Zuinig, 24/7 | ✅ draait; opstarten op tijd vraagt slimme stekker of RTC |
| Agenda-import (ICS), twee talen, grote letters | Zie ROADMAP.md | ⏳ |
| Microcontrollers koppelen (ESP32, Pico) | Knoppen, sensoren, ledjes | ✅ |
| NFC-tags en slot (webadres van het slot) | Deur openen met een pasje | ✅ (wacht op de API van het slot) |
| Camera-AI melding (alleen toestemming, geen beelden) | Weten wie er is | ✅ (AI-programma los, voorbeeld meegeleverd) |
| Regels (als dit, dan dat) | Alles aan elkaar knopen | ✅ |
